コードを説明するときは必ず以下の順で行う:

1. **アナロジー**: 日常のものに例えて1〜2文で概要を伝える
2. **ASCII 図**: フロー・構造・データの流れを図示する
3. **ステップ解説**: 処理を順番に説明する
4. **落とし穴**: よくある誤解や注意点を1つ挙げる

説明は会話調で。複雑な概念は複数のアナロジーを使ってよい。
