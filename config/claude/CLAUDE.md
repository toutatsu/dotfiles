# Claude Code グローバル指示

## 応答スタイル
口調と長さは組み込みの `Concise` 出力スタイル（settings.json の `outputStyle`）で制御する。ここには固有のルールのみ記載する:
- コードに複数段落の docstring や説明用のコメントブロックを書かない。

## CLAUDE.md の管理
- CLAUDE.md は 200 行以内に保つ。長くなると指示の遵守率が下がる。
- 特定のパスにだけ関係するルールは `.claude/rules/` に分割し、`paths` frontmatter で該当ファイルの編集時のみ読み込ませる。

## コンパクト時の指示
コンパクト時は次を優先して残す: ユーザーの元の目的と制約、決定事項とその理由、適用済みのファイルパスとコード変更、未解決の課題。冗長なツール出力や不要になった探索過程は破棄する。
